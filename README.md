# hwfefu

HWFEFU Project

## Getting Started

VariantCode: RAM-LOC-MOD_B7_LONG_PRESS_MENU

Stack: Flutter/Provider/Dio

Used endpoints: /api/location/{idLocation}; /api/character/{idCharacter}; /api/character/avatar/{idAvatar}

Required modificator: Long press any item in the location list to display following actions: Add to Favourites, Share, Display Details.

Additionally, every API location was provided with correspoding information about its API characters and their API images.

Every route and feature of the app was screenshoted and added to the folder Screenshots at the root of the repository. Moreover, a short video of the app running on Google Pixel 9 Pro XL API 36 is available at Screenshots too.

Built with Flutter 3.41.2
